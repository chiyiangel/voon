# 设置入口与菜单栏讨论

> 后续更新：用户已确认[侧栏分类设置窗口](2026-11-12-settings-sidebar.md)，扫描、读取重试和封面缓存维护现在集中到设置。下文保留原讨论记录；Q2、Q7 的入口划分以新决定为准。

用户要求：设置类的信息独立放到 menubar，macOS 使用顶部栏。两轮讨论的 Q1–Q9 均已得到用户确认；本文件记录最终范围和对应验收标准，尚未修改应用实现。

## 当前实现事实

- 主浏览区工具栏下固定显示“设置 · 音乐库”；打开设置后替换主内容区。
- 设置包含本地索引路径、新建索引、音乐目录增删、忽略规则、增量重新扫描和说明文字。
- 首次使用页面另有选择文件夹与开始扫描入口。索引不可用页面另有中文原因及“保留原库，新建索引”恢复入口。
- 当前没有注册应用菜单。
- 本地锁定 GPUI 0.2.2：macOS 的 `set_menus` 可创建屏幕顶部应用菜单；Linux 实现仅保存配置，不能直接视为已有可见菜单，需要实现窗口内的可见菜单栏。
- 当前关闭任意 GPUI 窗口都会触发应用退出；新增设置窗口时需修正该行为，才能满足已确认的关闭规则。
- 当前打开设置只切换可见状态，未清除编辑草稿；新建索引成功后会替换 AppState，已有扫描保护但尚未检查专辑或封面草稿。独立设置窗口需补齐已确认的操作保护。
- 当前配置即时保存：添加目录随即启动扫描，忽略规则在下一次扫描生效；没有统一“保存设置”按钮。移除目录已有确认流程。
- 当前设置操作的大部分错误显示在主窗口扫描条；独立设置窗口需要让用户在操作位置看见错误和受限原因。

## 已确认边界

用户先以“都 ok”接受 Q1–Q3，随后以“ok”接受 Q4–Q9 的推荐方案。当前决策前沿已清空，无待回答的产品分支。

应用设置与音乐整理分开：音乐目录（Library root）增删、忽略规则、本地索引路径展示与已有的新建索引操作归设置；增量扫描、失败重试和强读标签属于日常资料库操作。已有 User tag、Manual collection、专辑编辑、封面选择、合并拆分和来源比较继续属于内容上下文。

macOS 通过屏幕顶部原生应用菜单“Voon → 设置…”打开设置；Linux 通过应用窗口顶部可见菜单栏打开设置。主浏览区常驻的“设置 · 音乐库”入口移除，配置详情也从中央浏览区迁到独立窗口。

打开设置只负责显示或聚焦窗口，不切换当前本地资料库、不清除浏览选择或未提交编辑。设置窗口非模态，主窗口仍可操作。

## 第二轮已确认决定（Q4–Q9）

- Q4：Linux 在应用窗口顶部提供可见菜单栏，同样通过“设置…”打开独立窗口。
- Q5：设置窗口为非模态单实例，重复打开时聚焦已有窗口；关闭设置不退出应用、不停止扫描。关闭主窗口沿用当前退出应用的行为。
- Q6：macOS 的设置、关闭当前窗口、退出分别使用 `⌘,`、`⌘W`、`⌘Q`；Linux 使用 `Ctrl+,`、`Ctrl+W`、`Ctrl+Q`。菜单显示对应快捷键。
- Q7：按音乐目录选择的增量扫描放入“资料库 → 重新扫描 → 音乐目录”；失败重试与强读标签保留在待处理和专辑上下文，进度和取消仍在主窗口反馈区。
- Q8：首次使用的引导按钮打开设置来添加目录；索引不可用页保留原因和“新建索引…”恢复入口。正常浏览区不再常驻设置行。
- Q9：配置即时保存；添加目录后启动扫描，忽略规则下一次扫描生效并标明时机。设置始终可打开查看；扫描时禁用音乐目录增删和新建索引并说明原因，忽略规则仍可保存供下一次扫描使用；专辑或封面有未提交编辑时阻止新建索引，需先保存或取消编辑。操作错误在设置窗口内显示。

## 验收标准

以下场景将已确认决定转为可检查的行为，不增加新的功能范围。

| 场景 | 通过标准 | 对应决定 |
| --- | --- | --- |
| 平台入口 | macOS 屏幕顶部“Voon → 设置…”可用；Linux 窗口顶部有可见菜单入口；正常浏览区不再常驻设置行或嵌入配置详情 | Q1、Q3、Q4 |
| 打开、重复打开和返回浏览 | 首次打开设置出现独立窗口；再次打开聚焦同一窗口；主窗口仍可操作；仅打开或关闭设置不改变浏览位置、选择和编辑草稿 | Q3、Q5、Q9 |
| 关闭与退出 | 扫描期间关闭设置，应用和扫描继续；关闭主窗口按既有行为退出；关闭当前窗口与退出应用的菜单动作、快捷键符合各平台约定，快捷键显示在菜单中 | Q5、Q6 |
| 日常资料库操作 | “资料库 → 重新扫描”列出音乐目录；选择某目录仅对该目录发起增量扫描；失败重试、强读标签仍可从对应内容上下文操作；主窗口保留进度与取消反馈 | Q2、Q7 |
| 首次使用与索引故障 | 无音乐目录时可通过引导打开设置并添加目录；索引不可用时仍能读到原因并进入新建索引流程，相关保护规则同样适用 | Q8、Q9 |
| 保存与生效时机 | 配置无需统一“保存设置”；添加目录随即启动扫描；忽略规则保存后标明“下次扫描生效”，不改变当前扫描已采用的规则 | Q9 |
| 扫描中的保护 | 扫描期间可打开设置、查看配置、保存忽略规则；音乐目录增删和新建索引不可执行，并能在设置窗口看到受限原因 | Q9 |
| 未提交编辑保护 | 专辑或封面有未提交编辑时，打开设置保留草稿；新建索引被阻止并提示先保存或取消编辑，不静默丢弃草稿 | Q9 |
| 操作反馈与移除目录 | 设置操作失败时，原因在设置窗口内可见；目录移除保留已有确认和数据保护语义，不删除音乐文件，保留既有编辑、User tag 与 Manual collection | Q2、Q9 |

用户已单独确认测试安排：主要复用 voon-app 应用状态层，配套使用既有 voon-core 公共接口回归；原生菜单、快捷键和多窗口行为进行实际窗口验收，不新增内部测试接缝。
