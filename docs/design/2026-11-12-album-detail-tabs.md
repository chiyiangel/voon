# 专辑右栏分类标签

用户确认「分类标签」原型后实现。右栏仍为 340px，专辑摘要和四个分类固定在顶部，分类内容单独滚动。

- 概览：作曲家、演奏者、年份、唱片编号；其余资料、字段来源比较按需展开，标签和手动合集只显示摘要。当前数据模型没有唱片公司字段，因此使用唱片编号。
- 曲目：第一碟默认展开，其余碟可展开；曲目默认只显示编号、标题、时长。点击后显示演奏者、音频规格、文件路径、CUE 区间及播放器入口。
- 整理：沿用标签和手动合集的添加、移除功能。
- 文件：附件图片、真实来源目录、Finder / 文件管理器入口；读取状态默认折叠，重读操作链接到设置。

顶部保留选封面、编辑资料和外部播放器操作。离线时隐藏播放器入口；读取提示集中为一行，点击转到文件页展开详情。规格一致的专辑显示统一规格，混合规格显示「多种音频规格」。

分类切换保留当前专辑和展开状态。换专辑时保留所选分类，但重置资料、来源、读取状态、碟片和曲目的展开状态。各页使用独立滚动标识。

验证：GPUI 交互测试覆盖分页、逐碟/逐轨展开、换专辑重置、编辑入口；原有专辑资料、CUE、附件、标签与合集测试保留。通过 workspace 测试和严格 Clippy 检查。原生预览使用独立索引、两碟十二轨测试音乐库；自动化无法点击透明标题栏主窗口，改用标准标题栏并预选专辑的临时验证入口，确认四页布局、单曲展开和长路径换行。临时入口不进入正式程序。
