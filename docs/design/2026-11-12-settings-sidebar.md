# 设置窗口：侧栏分类

用户审阅「侧栏分类」「顶部标签」「折叠分组」交互原型后，明确选择侧栏分类，并要求把设置相关功能集中到同一窗口。

本决定更新此前 [设置入口与菜单栏讨论](2026-11-12-settings-menubar.md) 的 Q2、Q7：扫描、失败读取重试、所选专辑标签重读和封面缓存维护均集中到设置。主浏览界面保留状态反馈和前往设置的快捷入口；专辑编辑、封面选择、标签、手动合集等音乐整理操作仍属于内容本身。

## 窗口与分类

沿用非模态、单实例设置窗口及 `⌘,` / `Ctrl+,`。重复打开保留当前分类；菜单和上下文链接可直达指定分类，不改变专辑选择或编辑草稿。关闭设置不会退出应用或取消扫描。内容可滚动，配色遵循系统明暗模式。

| 分类 | 已实现的功能 |
| --- | --- |
| 音乐目录 | 目录列表、连接状态、重新检测连接、添加及使用建议目录、移除确认、扫描与规则快捷入口 |
| 扫描与读取 | 各目录增量重扫、任务状态、取消、空扫描确认、逐项失败重试、所选专辑强制重读标签 |
| 忽略规则 | 各目录忽略子文件夹的增删、离线时移除规则、折叠查看内置规则、下次扫描生效说明 |
| 本地数据 | 当前索引路径、索引故障说明、确认后另建空索引、封面缓存进度和位置、重试失败封面 |

菜单简化后，设置统一由「Voon → 设置…」或快捷键进入，四个分类在设置窗口内选择，不再在「资料库」菜单重复。关闭窗口位于「窗口」菜单；macOS 应用菜单保留系统服务、隐藏和退出操作。主窗口不再展示详细封面缓存统计和维护按钮；离线、扫描状态及读取问题引导到对应设置页。索引故障页也转到「本地数据」完成确认和创建。

本轮沿用现有底层操作，未新增备份、恢复、索引搬迁或自动扫描偏好。

## 数据保护与验证

保留扫描期间目录增删及索引切换限制、未保存编辑和封面草稿保护、忽略规则下次扫描生效、目录移除保留整理内容、索引新建不覆盖旧文件等约束。新建索引增加解释切换后果的确认步骤。

自动化验证：

- `cargo test -p voon-app --tests`：原有应用测试通过。
- `cargo test -p voon-app --test settings_window`：新增四项真实 GPUI 点击测试通过，覆盖分类导航与草稿保留、索引确认/取消/创建、扫描时阻止移除与关闭设置不取消扫描、重复打开复用窗口并直达分类。
- `cargo clippy --workspace --all-targets -- -D warnings`、格式检查和原生构建通过。

macOS 实际窗口使用独立应用 `Voon Settings Preview` 及 `target/settings-ui-validation/preview.sqlite3` 验证。已目视核对四个分类、长路径换行、索引创建确认及取消；点击重扫后显示扫描完成，点击失败项重试后显示本轮重试结束；关闭设置后主窗口继续显示。没有用用户的正常资料库执行验证操作。

Linux 菜单参与本机类型检查，尚未进行 Linux 实际窗口验证。其余历史里程碑的待验收项不由本次验证替代。
