# 不同发行保持独立专辑

Album 继续表示一份具体发行。首版与重制版各自保留独立的碟片、曲目和发行资料，通过 Version group 表达相关版本；同一份文件在 NAS、本机等位置的存放实例称为 Copy。用户在 Roon 对照讨论的第一轮 Q2 中确认了这一边界。

我们选择保留发行差异，而不把相关版本汇成一张多碟 Album。现有合并与拆分继续用于纠正专辑结构；版本关联与副本管理分别表达另外两种关系，避免后续整理和数据迁移混淆它们。

这一决定确定领域含义，不指定数据库身份方案，也不决定副本之间是否共享人工编辑、自动关联规则或默认展示版本；这些仍需后续讨论。术语见仓库根目录 GLOSSARY，下一轮可靠性范围见 `docs/specs/0002-library-reliability-and-protection.md`。
