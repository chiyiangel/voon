# 资料库备份保留离线状态

实施延期：用户最新决定本轮不实现备份与恢复。以下保留为后续设计，不构成本轮交付或验收要求。

Library backup 保留备份时的本地资料库状态，包括已知专辑、人工编辑、标签与合集及顺序、忽略规则、封面选择和已缓存缩略图，以及合并拆分和撤销所需的完整记录。恢复到空的本地库后，NAS 未连接时仍应能够浏览这些资料；音乐文件由独立备份承担。用户在第二轮 Q8 中确认了这一范围。

我们选择保留完整的本地状态，而不只导出人工字段：原文件可能已经变化或暂时不可用，重扫无法重建同一时点的浏览结果、来源证据和撤销基线。尚未缓存的封面不会因恢复而变成已缓存；备份承诺的是备份时的已知状态。

此决定确定未来备份范围，不指定文件格式。保留策略与恢复保护的讨论一并延期；Q11 的频率没有被接受，当前不再追问。后续重启备份开发时再核对具体条款。
