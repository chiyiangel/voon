# 保护当前资料库后再恢复

实施延期：用户最新决定本轮不实现备份与恢复。以下恢复和保护措施保留为后续设计，不构成本轮交付或验收要求。

恢复将资料库整体回到所选备份的状态。待恢复资料先在独立位置完成校验及受支持的迁移；存在且完好的当前库必须先生成并验证独立保护备份，再切换到恢复结果。保护或校验失败时保留当前库，源备份原样保留。用户在第三轮 Q13 中接受这一原则。

我们接受额外的暂存空间和恢复步骤，以保留回到恢复前状态的能力。当前库已损坏时，先保留原文件的隔离副本，不把它当作已验证可恢复的备份；隔离失败则停止覆盖。保护份不参与普通自动备份轮换。

同一原则可供未来结构升级使用，本轮不实现升级前自动备份。按 Q10 的范围，本轮从新建库重扫开始，不新增本轮前旧库迁移要求。恢复相关界面细节随功能延期。
