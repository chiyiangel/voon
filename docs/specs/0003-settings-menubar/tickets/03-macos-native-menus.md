# 03: macOS 原生菜单与目录重扫

**What to build:** macOS 用户从屏幕顶部原生菜单管理设置与应用窗口，并通过资料库菜单选择一个音乐目录进行增量重扫；主浏览区释放设置行占用的空间。

**Blocked by:** [02 独立设置窗口与共享命令](02-separate-settings-window.md)

**Status:** in-progress

- [ ] 屏幕顶部原生应用菜单提供“Voon → 设置…”及退出动作，并提供关闭当前窗口命令，复用 02 的窗口和共享操作。
- [ ] 菜单显示 `⌘,`、`⌘W`、`⌘Q` 等对应快捷键；主窗口或设置窗口获得焦点时均按约定执行，重复打开设置不产生第二个窗口。
- [ ] “资料库 → 重新扫描”按当前 Library root 列出明确目录；选择后仅该目录增量扫描，进度和取消仍在主窗口。
- [ ] 菜单随目录增删及成功新建索引更新；不存在、已移除、无可用目录或当前受限的操作不发起扫描，执行时复查共享保护。
- [ ] macOS 菜单可用后，移除本平台常驻“设置 · 音乐库”行和设置内重扫按钮；设置配置、失败重试与强读标签仍从各自约定位置使用。
- [ ] 不新增扫描全部目录命令、菜单栏状态图标或后台常驻行为；不改变音乐文件和增量读取规则。
- [ ] 状态层验证目标目录与保护，复用真实 worker 读取数回归；实际 macOS 窗口验证菜单可见、动作、快捷键、焦点和旧入口移除。

**Demo:** 添加两个 Library root，从顶部菜单选其中一个重扫，确认只扫描该目录；从“Voon → 设置…”打开并重复聚焦设置，使用关闭当前窗口命令后主窗口和扫描继续。

**User Stories:** 1、3、18、20、22–24。

规格：[0003 菜单栏与独立设置窗口](../../0003-settings-menubar.md)。通用约束与实施前沿见[工单索引](README.md)。

## 实施记录（2026-11-12）

代码已实现，平台验收未完成，状态保持 `in-progress`：

- `application/native_menu.rs` 在 macOS 安装“Voon → 设置… / 关闭当前窗口 / 退出 Voon”和“资料库 → 重新扫描 → 音乐目录”，复用 02 的动作、窗口协调和快捷键绑定。原生菜单从同一键位表取得快捷键显示。
- 重扫动作用完整 `PathBuf` 标识来源。菜单观察共享 `AppState`，仅在目录列表、离线标记或操作保护变化时重建；扫描进度和封面等通知不会反复重建菜单。成功切换索引后也由同一观察关系读取当前来源。
- GPUI 0.2.2 按动作类型验证原生菜单可用性，没有菜单项的独立 enabled 字段。不可用项使用未注册处理器的 `DisabledMenuItem` 动作；无目录、索引不可用、扫描期间和已知未挂载目录都有灰色项或说明。业务执行继续由共享重扫命令检查保护，并由 `start_scan` 检查当前目录成员和离线状态。
- 沿用已确认的应用状态 / 真实 worker 接缝，在 `rescan.rs` 增加三个共享命令回归：两个来源只扫描所选来源且沿用增量读取；已排队动作执行前移除来源不误扫其他目录；取消尚未消费时不替换当前 worker。复用既有业务行为，不新增菜单内部数组或平台快照测试。
