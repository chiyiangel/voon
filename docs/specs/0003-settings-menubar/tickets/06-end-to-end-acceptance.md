# 06: 完整用户旅程与平台联验

**What to build:** 用户可以完整走通启动、设置、浏览、扫描、编辑保护和索引恢复流程；修正集成后出现的交错问题，交付可复核的自动化与平台验收记录。

**Blocked by:** [03 macOS 原生菜单与目录重扫](03-macos-native-menus.md)；[04 Linux 可见菜单与目录重扫](04-linux-visible-menus.md)；[05 首次使用与索引故障引导](05-startup-and-index-recovery.md)

**Status:** in-progress

- [ ] 以前五票各自完成的验证为基线，联合检查菜单、快捷键和引导只打开一个设置窗口；正常浏览不再有常驻设置行、中央配置面板或设置内重扫入口。
- [ ] 选中 Album、滚动、搜索和筛选并打开专辑或封面草稿，再打开、关闭和重新打开设置，浏览位置与草稿保持；尝试新建索引被阻止，明确保存或取消后才可继续。
- [ ] 在目录选择或移除确认与另一窗口启动扫描交错时保护仍有效；扫描中关闭设置、保存忽略规则、取消任务及再次打开设置后状态一致，不产生重复扫描或无声切库。
- [ ] 新建索引成功后主窗口、设置与目录菜单更新；取消、失败和不可用索引恢复均遵循原文件保留规则，配置持久化经重开验证。
- [ ] User tag、Manual collection、编辑、Cover 选择、合并拆分、Field source 比较、Needs attention 重试和专辑强读标签继续在原有内容上下文使用。
- [ ] 使用临时音乐目录和隔离索引检查文件只读及人工整理保留，不修改用户正常索引；不引入备份，也不重做约 20 张真实专辑验收。
- [ ] 工作区测试、严格 Clippy、格式与差异检查通过；实际记录 macOS、Linux X11、Wayland 构建及窗口结果，未验证的平台明确保留未完成状态，不以状态层或其他平台替代。
- [ ] 将本规格的实现与验收结果单独记录，不关闭或改写 0001、0002 已有的未完成外部验收，也不修改父规格来迁就实现。

**Demo:** 从隔离空库启动，配置两个目录，菜单选择其中一个增量扫描，打开并关闭设置确认任务继续；编辑 Album 后验证新建索引保护，再完成独立索引恢复并重开验证配置，逐平台核对相同行为。

**User Stories:** 9、25–27；完整旅程联验 1–40。
