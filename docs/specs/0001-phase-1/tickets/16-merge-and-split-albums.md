# 16: 合并与拆分专辑

**What to build:** 把被误分成多张的 Album 合并为一张（各自成为 Disc，可调整 Disc 顺序），或把一张 Album 拆成多张（按 Disc 或按选中的 Track）。操作可撤销，结果作为用户数据保存，重扫后保留；涉及的用户编辑按规则合并。需要在 voon-core 中新增合并 / 拆分 / 撤销接口及其持久化。

**Blocked by:** 10 编辑专辑信息、14 待处理视图；外部门槛：原型审核通过（PR #1 / https://voon-design-canvas.vercel.app）

**Status:** in-progress

- [ ] 可把一张 Album 按 Disc 或选中的 Track 拆成多张

## 实现与验证记录（2026-11-11）

- 扫描原始 Album 快照与有序结构操作分开持久化；完整、部分扫描和撤销均在本地事务中重放。支持跨 Library root 合并、主信息源、Disc 顺序、按 Disc 或所选 Track 拆分，以及依次撤销最近操作。音乐库文件不变。
- 主信息源的非空值优先，其余补缺；标签与手动合集取并集，封面优先主源。原输入的用户数据仍保留；撤销把结果相对初始状态的后续编辑带回原输入。多个拆分结果产生相冲突的新字段、封面或合集顺序时明确拒绝撤销，先统一后可重试。
- 普通 Disc 以真实目录保持稳定，同目录多张 Disc 则用音频/CUE 身份区分。合并与拆分结果保存真实来源目录，供封面、附件与文件管理器操作使用。确认改名会事务性重映射结构中的路径，不改元数据文字。
- 被忽略或删除的扫描输入不会从旧快照复活；结构选择和用户数据仍保留。移除根目录也保留结构选择，所有依赖根目录重新添加后自动恢复。存在结构选择的根目录重扫时保留当前专辑区，仅更新进度，完成后统一刷新。
- `cargo test -p voon-core --test album_structure --offline`：12 项通过，覆盖重启/重扫/撤销、不同标题/标签/合集/封面的合并及后续差异保留、跨根移除重加、两种拆分、虚拟轨与冲突拒绝、同目录多 CUE 重排、删首文件不丢分组、忽略输入不复活、确认改名、连续两次撤销及真实来源目录。新增接口先观察编译失败；同目录多碟、删首文件、根移除和改名确认等交叉场景先观察行为失败，再修复。
- `cargo test -p voon-core --test migrations --offline`：旧 v2 索引迁移回归通过。GPUI 状态层已验证确认/取消、主源与顺序、选中合并结果、曲目拆分和撤销恢复；GPUI `album_structure` 2 项通过。主代理实际窗口验证 4 张 → 合并后 3 张 → 重扫保留 → 按碟拆分 5 张 → 连续两次撤销恢复 4 张；全套 123 项通过。
