# 04: 当前 Cover 持久化与离线重开

**What to build:** 现有浏览或封面选择流程成功加载的当前 Cover 写入本机持久缩略图，退出后断开 NAS 仍可显示；自动图和手选图使用同一套关联与失效规则。

**Blocked by:** 无（可立即开始）

**Status:** ready-for-agent

- [ ] 外置图片、内嵌图片及指定内嵌索引都能生成可重开的本地缩略图。
- [ ] 资产完整写入并可读取后才标为已就绪，持久数据及其 Cover 关联经应用重开保留。
- [ ] 已就绪封面在退出进程、断开来源、重新启动后仍可在网格和详情显示。
- [ ] 更换选择或确认来源变化时更新关联；迟到任务不能覆盖较新的选择。
- [ ] 单项读取、解码或缓存损坏不清空 Album、选择或其他资产；无有效缓存时不冒充已就绪。
- [ ] 内存淘汰不删除应保留的持久资产；后台工作有界，产物不写入 Library root。
- [ ] 用真实图片、真实本地存储和重开场景验证，不只让假加载器返回成功。

**Demo:** 浏览几张自动封面并手选一张内嵌图片，待加载成功后退出、断 NAS、重启；这些图片仍能显示。

**User Stories:** 56、59–63、65–67。

**切片边界:** 本票把现有“已请求的封面”流程变为可持久使用；全部未浏览 Album 的后台覆盖和全局进度在 [10 全库封面预缓存与失败重试](10-library-cover-prefetch.md)交付。
