# 03: CUE 时长与曲目演奏者完整呈现

**What to build:** Virtual track 按已知 CUE 边界显示时长，详情逐轨显示已解析演奏者；即使 DFF 标签不支持也不丢失 CUE 本身提供的资料。

**Blocked by:** 无（可立即开始）

**Status:** ready-for-agent

- [ ] 起点 0、终点 13500 帧的 Virtual track 显示 180000 ms，不依赖标签读取成功。
- [ ] 末轨总长可知时显示剩余时长，不可知时如实显示未知。
- [ ] 两首不同演奏者的曲目在详情各自显示正确演奏者。
- [ ] 公开查询、数据库往返及应用重开后仍保留时长、演奏者和映像/CUE 来源。
- [ ] 默认播放器入口准确说明打开整个映像，不引入定位播放、DFF 属性解析或切分文件。
- [ ] core 与状态层场景通过，并核对实际窗口中时长和演奏者确实被渲染；音乐与 CUE 内容不变。

**Demo:** 打开两轨 DFF 加 CUE，第一轨显示 3:00，末轨总长未知，两个演奏者分别可见；重开后不变。

**User Stories:** 48–54。
