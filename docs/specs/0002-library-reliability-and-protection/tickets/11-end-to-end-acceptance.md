# 11: 故障交错与真实样本联验

**What to build:** 将前面各条已验证的行为放到同一资料库与真实窗口中联验，修正扫描、编辑、候选和封面任务交错时的集成缺口，提供可复核完成证据。

**Blocked by:** [03 CUE 时长与曲目演奏者完整呈现](03-cue-duration-and-performers.md)；[05 新建索引与资料库版本保护](05-new-index-and-version-guard.md)；[06 取消离线与结构整理保持一致](06-scan-interruption-and-organization.md)；[07 重试失败项与强制重读标签](07-retry-and-force-reread.md)；[09 全部现有字段的候选与编辑一致性](09-all-field-candidates.md)；[10 全库封面预缓存与失败重试](10-library-cover-prefetch.md)

**Status:** ready-for-agent

- [ ] 临时故障库覆盖本规格的核心场景，包含局部不可读、相同 stamp 恢复、取消、换封面及过期任务。
- [ ] 使用约 20 张用户认可的真实专辑，覆盖多编码 CUE、整轨、多碟、DSD、混合标签、外置和内嵌封面。
- [ ] 实际窗口确认失败提示、候选比较、逐轨演奏者及离线冷启动封面，不用状态测试代替可见结果。
- [ ] 交错执行扫描、编辑、重试和封面更换后，公开查询、应用状态、导航计数和持久资料一致，缺口在本票修正。
- [ ] 工作区测试、严格 Clippy、格式和差异检查通过，现有浏览、标签、Manual collection、忽略和结构纠错无回归。
- [ ] 音乐库文件集合、内容及修改时间保持不变，本地产物不落入 Library root。
- [ ] 保留 macOS 与 Linux 的构建和平台要求；不可用环境明确记为未验证，不将平台或用户手工验收标为已完成。
- [ ] 不因联验重新引入备份恢复、旧库迁移、在线资料、相关版本或新的测试接缝。

**Demo:** 在一套受控资料库及选定真实样本中演示故障、恢复、重启离线和人工整理全流程，并附各平台的实际验证记录。

**User Stories:** 4、6、73–75，以及前述各功能的交错回归。

**外部验收条件:** 真实样本及读取位置由用户认可；实际 NAS 和窗口验收在相应环境可用后完成。功能票自己的自动验证不依赖本票才开始。

规格：[0002 资料库扫描可靠性与离线浏览](../../0002-library-reliability-and-protection.md)。通用约束与实施前沿见[工单索引](README.md)。
