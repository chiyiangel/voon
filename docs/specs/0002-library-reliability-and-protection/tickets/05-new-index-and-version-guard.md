# 05: 新建索引与资料库版本保护

**What to build:** 用户可保留原库、从新建资料库扫描；已有未知或较新版本的库得到中文提示，在任何写入性初始化之前拒绝改写。

**Blocked by:** 无（可立即开始）

**Status:** ready-for-agent

- [ ] 新库能创建、扫描、重新打开并继续正常使用。
- [ ] 已有更高结构版本或无法识别身份的库，在写入性初始化及迁移前被拒绝。
- [ ] 拒绝不会改写原库及已有相关文件，也不自动降级、清空或把未知库当成空库。
- [ ] 不兼容提示可见且可理解，说明保留原库、新建索引重新扫描的选择。
- [ ] 旧库文件不因创建新库而被删除或覆盖，不增加旧库迁移和来源补齐流程。
- [ ] core 公共接口验证文件不变与新库往返，应用状态验证相应可见提示和新建流程。

**Demo:** 选择一个未知库或较新库，看到拒绝说明且原文件不变；随后从新库扫描成功。

**User Stories:** 1、2、68–71。

规格：[0002 资料库扫描可靠性与离线浏览](../../0002-library-reliability-and-protection.md)。通用约束与实施前沿见[工单索引](README.md)。
